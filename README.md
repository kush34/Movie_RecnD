### **Movie Recommendation App**

![image](https://github.com/user-attachments/assets/db104676-c2ea-48c6-a2ba-675fab2f04f6)

**Movie Recommendation App**, a platform designed to help users discover movies and TV shows based on their preferences. With features like infinite scrolling, detailed movie views, and personalized recommendations, this app ensures an engaging and user-friendly experience.

## Features

**1. Discover Section**

Explore a wide range of movies and TV shows.

Infinite scroll functionality for seamless browsing.

**2. Detailed Movie Views**

View full-page details for any movie or TV show.

  Includes:
  
    * Backdrop images
    
    * Descriptions
    
    * Provider names
    
    * Watch trailer buttons

**3. Genre-Based Recommendations**

Explore featured movies and shows from similar genres.

**4. Responsive Design**

Optimized for various devices to provide a smooth experience across desktop, tablet, and mobile.

**5. Built with React**

Fast, modular, and scalable frontend.

## Tech Stack

Frontend: React

CSS Framework: Tailwind CSS

Deployment: Vercel

## Installation

* Clone the repository:
```
git clone https://github.com/your-username/movie-recommendation-app.git
```
* Navigate to the project directory:
```
cd movie-recommendation-app
```
* Install dependencies:
```
npm install
```
* Start the development server:
```
npm run dev
```
* Open your browser and visit:
```
http://localhost:5173
```

* Deployment

This app is live on Vercel. Visit the deployed app here.
